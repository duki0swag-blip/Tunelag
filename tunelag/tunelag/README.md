# TunelLag

Lag switch local para Free Fire en Android. Sin root, sin servidor externo.
Tuneliza solo el tráfico del juego y descarta UDP del servidor en ráfagas cortas.

## Compilar
Push a la rama principal lanza GitHub Actions. Descarga el artefacto
`TunelLag-apk` desde la pestaña Actions y descomprime el `.apk`.

## Uso
1. Activar túnel y aceptar el diálogo de VPN.
2. Excluir la app de la optimización de batería.
3. Entrar a partida y comprobar que sube el contador de endpoints.
4. Activar la burbuja flotante y conceder el permiso de superposición.
5. Tocar el círculo para cortar. Mantener pulsado para quitarlo.
